# Ampero Mini для Android

Прототип редактора для гитарного процессора Hotone Ampero Mini. Процессор подключается к телефону по USB-C (OTG).

Что умеет сейчас:
- находит Ampero Mini и подключается к нему через стандартный Android MIDI (`android.media.midi`), драйвер не нужен;
- читает имена всех 198 пресетов (2 банка по 99);
- переключает пресет по нажатию;
- подсвечивает пресет, выбранный кнопками на самом процессоре.

Описание протокола: `E:\ampero-captures\PROTOCOL.md`.

## Структура

| Файл | Что внутри |
|---|---|
| `protocol/Ampero.kt` | сборка и разбор SysEx-сообщений, чтение пресета по кускам |
| `protocol/MidiFramer.kt` | нарезка входящего MIDI-потока на сообщения |
| `midi/AmperoConnection.kt` | поиск устройства, открытие портов, запросы и ответы |
| `MainViewModel.kt` | состояние экрана, подключение и отключение |
| `PresetScreen.kt` | интерфейс на Jetpack Compose |
| `src/test/...` | тесты протокола на байтах из записей USB |

## Как собрать

1. Установи [Android Studio](https://developer.android.com/studio).
2. **File → Open** → папка `E:\ampero-android`. Studio сама скачает Gradle и Android SDK 35, просто соглашайся.
3. Тесты протокола: правый клик по `app/src/test` → **Run 'Tests in ...'**.

## Как запустить на телефоне

У телефона один USB-разъём, и его займёт процессор, поэтому отладку удобнее вести по Wi‑Fi:

1. На телефоне: **Настройки → О телефоне** → 7 раз нажать **Номер сборки**, чтобы включить режим разработчика.
2. **Для разработчиков → Отладка по Wi‑Fi** (Android 11+). В Android Studio: **Device Manager → Pair devices using Wi‑Fi**, отсканировать QR-код.
3. Запустить приложение кнопкой **Run**.
4. Подключить Ampero Mini к телефону кабелем USB-C ↔ USB-C (или через OTG-переходник).

Если процессор не включается от телефона, подключи его собственный блок питания.
